# DEEPWAKE feature audit

`GOAL.md` is the product specification. This document lists the 27 features it asks for and the 17 validation areas of its §20, with the files that build each and the checks that verify each. No feature is `Missing` or `Broken`.

How to read the table:

- **Spec source** is a section of `GOAL.md`.
- A name in double quotes is a test name. `node --test --test-reporter=spec tests/<file>` prints it. `npm test` runs all of them.
- `check:browser` with a letter is one check of `npm run check:browser`, named as in `tools/browser-check.mjs`.
- **Status** is `Working` when a named check asserts the behavior of the feature. It is `Partial` when the feature is built and a whole part of it has no named check. The note after the status names what no check asserts.
- `node tools/preview.mjs` gives an image. An image is not an assertion.

## Verification results

- `npm test`: 356 tests, 356 pass, 0 fail, in 2.7 s. Run for this document.
- `npm run check:browser`: 14 of 14 checks passed (A to N) in its last recorded run. It was not re-run for this document.
- `README.md`, "Measurements", holds the measured numbers and how each was taken.

## Deliberate deviations

Every place where the game differs from a number or a rule of `GOAL.md`.

1. **Route length.** §10 asks for "approximately 180–240 units of route length".
   - Measured: the course spans x 0 to 238 and y −2 to 84 (`LEVEL.bounds`). The spawn is at (4.5, 6) and the lift console at (229.5, 66): 225 units east and 60 up. The scripted main route (`MAIN` in `tests/route-steps.js`) moves ILO 467.23 units in 16479 steps: 277.78 east, 49.78 west, 146.65 up, 68.65 down. In mode `play` alone, without the ride of the lift and the walk onto the terrace, the path is 446.16 units in 14374 steps.
   - How: a one-off Node command for this document played `MAIN` with `Driver` and summed the distance ILO moved per step. No test or tool computes a route length.
   - Reason: not recorded. The route climbs through five wall-jump shafts and walks back west twice, so the walked path is about twice the width of the course.
   - Decision: kept. The width of the course, 238 units, lies inside the range of §10. The walked path does not.
2. **Duration of a first playthrough.** §1 asks for "approximately 8–12 minutes".
   - Measured: the scripted clean run ends at clock 119.82 s. The run that passes every machine without a hit ends at 119.69 s. The run with all three archives and `cache2` ends at 137.27 s (browser check J). No person has played the game for a measurement.
   - Reason: the script knows the course and waits only where a mechanism makes it wait.
   - Decision: not shown. No evidence meets or misses the target.
3. **Name of the pulse ability.** §8 calls it "Echo pulse", and §17 gives `Q — Echo Pulse` as a prompt.
   - Measured: the control lists, the prompt and the label of the energy meter say `Echo Pulse`. The touch button and the HUD chip say `Pulse` (`src/ui/ui.js`).
   - Reason: not recorded. The four action buttons carry one-word names: `Jump`, `Dash`, `Pulse`, `Use`.
   - Decision: kept. With touch controls the pause menu lists `Pulse` as the key and `Echo Pulse` as the action.
4. **`label` on sockets and switches.** No rule of `GOAL.md` concerns it.
   - Measured: `src/level/build.js` gives every socket and switch a `label`: `Circuit`, `Lift`, `Relay`, `Bridge`, `Latch`. The player never sees it.
   - Reason: the label names the object for the tests. The comment of the file says so.
   - Decision: kept. It is listed here because a reader of the level data may take it for a player-facing name.
5. **Instancing.** §19 says "Reuse geometries, textures, and materials; instance repeated rock and structural modules."
   - Measured: no module of `src/render/` uses `InstancedMesh`. The rock and the metal of the terrain are one merged mesh per region and material (`src/render/terrain.js`). After 600 frames and two restarts the scene holds 240 meshes on 176 geometries and 68 materials.
   - Reason: not recorded.
   - Decision: kept as built. Geometries and materials are reused, and the draw calls are held: at most 82 in a frame with every actor lit, against a budget of 150.
